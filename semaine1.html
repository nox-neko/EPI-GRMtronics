Mission technique : Decodage des trames CAN

Du 06/06/2026 au 23/06/2026, ma mission principale a été d'identifier et de décoder les trames de communication issues de diverses calculateurs de boîtes de vitesses automatiques.

Modèles étudiés :

  • Mercedes-Benz : 7G-TRONIC, 9G-TRONIC
  • Groupe VAG (Audi/VW/Skoda) : DQ200, DQ250, DQ380 / DQ381
  • Autre : Temic 722.8, Multitronic VL381

Méthodologie de Reverse-Engineering CAN

L'objectif était de capturer les trames associées aux requêtes d'information des capteurs de boîte :

  1. Capture initiale : Utilisation d'une valise de diagnostic automobile. Lors de l'interrogation d'un capteur, la valise génère une trame spécifique sur le bus.
  2. Analyse Sniffer : Utilisation des outils PCAN-View et PCAN-Trace pour espionner le réseau et isoler les ID de trames pertinents.
  3. Validation : Envoi manuel des trames isolées via PCAN-View (sans la valise) pour vérifier que le calculateur répond correctement.
  4. Intégration : Implémentation des trames validées dans le logiciel de banc de test interne à l'entreprise pour automatiser les contrôles.
